# Product doc: plan tiers and what's included

- **Starter**: per-seat, monthly or annual billing, core product only, no
  SSO, community support, best-effort SLA.
- **Business**: per-seat, annual billing only, SAML SSO, standard API rate
  limits (600 requests/minute), 99.9% SLA, business-hours support.
- **Enterprise**: per-seat, annual billing only, SAML SSO + SCIM, custom
  roles, audit log export, elevated API rate limits (negotiated), 99.9%
  SLA with credits, tiered support response targets, custom contract
  terms (DPA redlines, security questionnaires, MSA).

Overage and add-ons: additional API rate limit headroom is available as a
paid add-on on Business plans; Enterprise negotiates limits directly into
the contract. Professional services (onboarding, custom integration work)
are quoted separately, not bundled into subscription pricing.
