# Product doc: sub-processors

Northbound's current sub-processor list (published, updated as changes are
made, with 30 days' notice to customers before a new sub-processor
receives data):

- Google Cloud Platform: hosting, storage, and compute.
- SendGrid: transactional email delivery (notifications, digests).
- Segment: product analytics event pipeline, no customer content, only
  usage metadata.
- Stripe: billing and payment processing.

Customers on Enterprise plans can request email notification (rather than
just the published changelog) when a new sub-processor is added, and can
object during the 30-day notice window per the DPA's standard process.
