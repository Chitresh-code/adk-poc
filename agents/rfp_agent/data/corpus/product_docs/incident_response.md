# Product doc: incident response and breach notification

Northbound maintains a documented incident response plan, reviewed
annually and tested via a tabletop exercise once a year. Severity-1
incidents (confirmed customer data exposure) trigger notification to
affected customers within 72 hours of confirmation, consistent with GDPR
Article 33 timelines; this commitment is also written into our standard
DPA.

Customers are notified via the email on file for their designated security
contact plus an in-product banner for admins. We do not currently offer a
dedicated status-page subscription specifically for security incidents
separate from general availability incidents; both are posted to the same
public status page, tagged by category.
