# RFP / Security Questionnaire Agent

Reads an incoming RFP or security questionnaire, breaks it into individual questions, retrieves grounded answers from past responses and product docs, and drafts a reviewable response for presales.

## Try asking

- "Paste a security questionnaire and draft grounded answers for each question."
- "Are you SOC 2 certified? If so, which trust principles are covered?"
- "Do you offer an on-premise deployment option?"

See `data/sample_rfp.md` for a full sample questionnaire to paste or attach.
