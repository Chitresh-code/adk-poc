# Playbook: responding to a usage decline

When an account's monthly active users drop more than 15% quarter over
quarter with no obvious cause (a known layoff, a reorg, a planned pause),
the standard first move is a health-check call within one week, not a
generic check-in email: ask directly what changed, whether the original
champion is still using the product, and whether a competing tool has
entered the workflow. Pull the account's feature-adoption gap (features
they're paying for but not using) before the call so the conversation can
offer something concrete, not just ask questions. Escalate to the account's
CSM lead if the champion doesn't respond within a week.
