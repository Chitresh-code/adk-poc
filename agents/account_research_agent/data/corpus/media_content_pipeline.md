# Case study: Overlook Media content pipeline

Overlook Media, a mid-market digital media company, moved its content
metadata pipeline onto Northbound after a funding round funded a push to
scale editorial tooling. Their engineering leadership had been running the
pipeline on a patchwork of scripts and a single database instance that
couldn't keep up with a growing catalog. Northbound's managed pipeline
primitives let a two-person team rebuild the ingestion path in three weeks
instead of the quarter they'd originally scoped, freeing that headcount for
the CMS rebuild they'd been deferring.
