# RevOps CRM Hygiene & Forecasting Agent

Sweeps the CRM for missing, stale, or duplicate deal data, flags stalled deals, and sharpens the sales forecast against those flags. Read-only: it only ever reads from the CRM, it never edits or merges a record itself.

## Try asking

- "Sweep the CRM for hygiene issues and sharpen the forecast."
- "Which open deals are missing data or going stale?"
- "How does the sharpened forecast compare to what reps submitted?"
