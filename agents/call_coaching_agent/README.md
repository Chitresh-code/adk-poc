# Call Analysis & Coaching Agent

Takes one sales call (an uploaded audio file, an uploaded transcript, or pasted transcript text), scores it against a MEDDPICC-style methodology, surfaces competitor mentions and deal risk, and writes a coaching summary back to the CRM when a matched deal comes back flagged.

## Try asking

- "Paste a call transcript and score it against our sales methodology."
- "Attach a recording of a sales call and flag any deal risk."
- "What competitors came up on this call, and how risky is the deal?"

See `data/fixtures/` for sample call transcripts to paste or attach.
